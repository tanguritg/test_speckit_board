# Quickstart: Customer Complaint Board (Prototype)

## Prerequisites
- Modern web browser (Chrome/Firefox/Edge).
- A Gemini API Key (for live AI features).

## Setup
1. Clone the repository and checkout the `001-customer-complaint-board-ai` branch.
2. Open `index.html` directly in your browser.

## Using AI Features
1. Enter your Gemini API Key when prompted by the application (or set it in `localStorage.setItem('GEMINI_API_KEY', 'your_key')`).
2. Submit a complaint via the form.
3. Wait ~5-15 seconds for the AI response to appear.

## Staff Review Mode
1. Append `?mode=staff` to the URL to enable administrative controls.
2. Review, edit, or approve AI-generated responses directly on the board.
